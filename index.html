03 How I Test

My QA workflow, from requirement to release.

  1. 1
    Requirement Analysis

    Review the BRD/user stories and business flows with the BA to understand scope, acceptance criteria, and what is testable.

  2. 2
    Test Planning

    Define the test scope, approach, test types, environment, and timeline for the release.

  3. 3
    Test Case Design

    Write test scenarios and test cases — positive, negative, and edge cases — and prepare the test data.

  4. 4
    Test Execution (SIT)

    Run functional, integration, API, and end-to-end tests on web and mobile in the SIT environment.

  5. 5
    Defect Report & Retest

    Log reproducible defects in Jira, work with developers on the fix, then retest and run regression.

  6. 6
    UAT Support

    Support users during UAT — walk through scenarios, clarify issues, and track UAT findings until resolved.

  7. 7
    Sign-off & Release

    Complete the SIT/UAT reports and user manual, give QA sign-off, and verify the release is production-ready.
